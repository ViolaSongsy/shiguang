# Changelog

## Unreleased

### Added

- English and Chinese project documentation, a branded banner, and fictional-data screenshots.
- MIT license, contribution and security policies, issue/PR templates, deployment/privacy guides, and a roadmap.
- Node.js 22 configuration, GitHub Actions verification, and Dependabot update configuration.
- Integration coverage for cross-account entry isolation, dynamic-route deletion, and session invalidation on logout.

### Changed

- Upgrade Next.js 14 to 16 and React 18 to 19; migrate cookies and dynamic route params to asynchronous APIs.
- Replace `next lint` with ESLint flat configuration and generate route types before type checking.
- Clarify in-app privacy language about password hashing, readable journal storage, and browser speech processing.
- Exclude local data files and private keys from version control.

### Known limits

See [the roadmap](docs/ROADMAP.md), [security policy](SECURITY.md), and [privacy notes](docs/PRIVACY.md). Public source code is separate from the readiness of any hosted multi-user service.
